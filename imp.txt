=========================================
      QUIZIFY - PROJECT GUIDE
=========================================

Quizify is a modern, responsive web app built with Flask that allows you to
create, take, and manage custom quizzes with detailed feedback.

--- HOW TO RUN THE PROJECT ---

1. Prerequisites:
   - Python 3.x installed.
   - Required packages: flask, flask-sqlalchemy, flask-login, werkzeug.
   (Run: pip install flask flask-sqlalchemy flask-login werkzeug)

2. Start the Server:
   - Navigate to the project root folder (PEP_PRO).
   - Run the command: python run.py

3. Access the App:
   - Open your browser and go to: http://127.0.0.1:5000

--- IMPORTANT FEATURES ---

- REGISTRATION / LOGIN:
  Securely create an account to start managing your own quizzes.

- QUIZ CREATION:
  Navigate to "Create Quiz". Add a title, then add as many multiple-choice
  questions as you want.

- PROFILE MANAGEMENT (ACCOUNT):
  Go to the "Account" section in the menu to update your Full Name,
  Username, or Email.

- RESULTS & FEEDBACK:
  After finishing a quiz, you will see your score and a detailed
  breakdown showing which questions you got right, which you got wrong,
  and what the correct answers were.

- DELETE QUIZZES:
  On the home page, you will see a 'Delete' button for any quiz you created.

--- TROUBLESHOOTING ---

- DATABASE ERROR: If you see an error related to columns (like fullname),
  simply delete the 'instance/site.db' file and restart the project.
  The app will recreate a clean database automatically.

Enjoy Quizify!
